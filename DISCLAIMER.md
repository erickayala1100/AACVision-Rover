# Hardware Safety Disclaimer

This repository controls a physical mobile robot. It is an academic prototype, not a certified commercial safety system. Operation can cause property damage, injury, battery faults, electrical faults, data loss, or unintended motion.

Use is entirely at the operator's risk. Test with the wheels raised before every configuration change, maintain an immediate power-disconnect method, and do not operate near people, pets, stairs, traffic, glass, water, or fragile objects.
