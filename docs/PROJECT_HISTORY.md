# Project History and Advising

AAC Vision progressed through three major senior-project phases with different advisors.

- **Jenna Kloosterman — planning phase:** project definition, wiring diagrams, component selection, system layout, scheduling, and planning toward project deadlines.
- **Noel Ellis — construction phase:** parts ordering, rover construction, electrical wiring, and individual component tests.
- **Chuck Bland — integration phase:** final build integration, autonomous code testing, troubleshooting, and system refinement.

The software required many iterations because perception, motion, mapping, power, and obstacle behavior interact. A change that improved one metric sometimes reduced another. Examples included stricter target filters that rejected the real ball, faster approach code that lost the target, and more aggressive obstacle recovery that produced oscillation or unnecessary turns.
